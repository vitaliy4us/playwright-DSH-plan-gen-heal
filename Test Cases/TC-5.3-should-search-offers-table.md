# TC-5.3 Поиск по таблице предложений (should-search-offers-table)

**Предусловия:** открыта страница Top Deals (`https://rahulshettyacademy.com/seleniumPractise/#/offers`) в новой вкладке

| № шага | Описание шага | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | Открыть страницу предложений | Таблица отображает все строки с колонками «Veg/fruit name», «Price», «Discount price» | |
| 2 | Ввести «Orange» в поле «Search:» | Отображается только строка «Orange» с её ценой и ценой со скидкой | |
| 3 | Очистить поле поиска | Полная таблица восстанавливается | |
