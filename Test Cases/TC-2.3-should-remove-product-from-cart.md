# TC-2.3 Удаление товара из корзины (should-remove-product-from-cart)

**Предусловия:** открыта главная страница GreenKart (`https://rahulshettyacademy.com/seleniumPractise/#/`), корзина пуста

| № шага | Описание шага | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | Добавить «Brocolli - 1 Kg» в корзину | Счётчик «Items» показывает «1» | |
| 2 | Добавить «Cauliflower - 1 Kg» в корзину | Счётчик «Items» показывает «2» | |
| 3 | Открыть корзину и нажать «×» рядом с «Brocolli - 1 Kg» | «Brocolli - 1 Kg» больше не отображается в корзине; счётчик «Items» показывает «1»; счётчик «Price» показывает «60» (осталась только Cauliflower) | |
