# TC-3.2 Применение валидного промокода (should-apply-valid-promo-code)

**Предусловия:** открыта главная страница GreenKart, в корзину добавлено 3 шт. «Brocolli - 1 Kg» (₹120 за шт.)

| № шага | Описание шага | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | Открыть корзину и нажать «PROCEED TO CHECKOUT» | URL становится `#/cart`; «Total Amount :» равен 360 | |
| 2 | Ввести «rahulshettyacademy» в поле «Enter promo code» и нажать «Apply» | Появляется сообщение «Code applied ..!» | |
| 3 | Проверить расчёт скидки | «Discount : 10%» | |
| 4 | Проверить итоговую сумму | «Total After Discount : 324» (360 − 10%) | |
