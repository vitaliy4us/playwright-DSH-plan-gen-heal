# TC-3.1 Отклонение невалидного промокода (should-reject-invalid-promo-code)

**Предусловия:** открыта главная страница GreenKart, в корзину добавлено 3 шт. «Brocolli - 1 Kg» (₹120 за шт.)

| № шага | Описание шага | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | Открыть корзину и нажать «PROCEED TO CHECKOUT» | URL становится `#/cart`; сумма 360 | |
| 2 | Ввести «INVALID123» в поле «Enter promo code» и нажать «Apply» | Появляется сообщение «Invalid code ..!» | |
| 3 | Проверить расчёт без скидки | «Discount : 0%» и «Total After Discount : 360» остаются без изменений | |
