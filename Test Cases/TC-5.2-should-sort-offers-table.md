# TC-5.2 Сортировка таблицы предложений (should-sort-offers-table)

**Предусловия:** открыта страница Top Deals (`https://rahulshettyacademy.com/seleniumPractise/#/offers`) в новой вкладке

| № шага | Описание шага | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | Открыть страницу предложений | Статус сортировки показывает «Sorted by name: descending order» | |
| 2 | Нажать заголовок колонки «Veg/fruit name» | Статус сортировки показывает «Sorted by name: ascending order»; первая строка — первая по алфавиту среди отображаемых | |
| 3 | Нажать заголовок колонки «Price» | Статус сортировки отражает сортировку по цене | |
