# TC-2.1 Добавление одного товара в корзину (should-add-single-product-to-cart)

**Предусловия:** открыта главная страница GreenKart (`https://rahulshettyacademy.com/seleniumPractise/#/`), корзина пуста (Items: 0)

| № шага | Описание шага | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | Нажать «ADD TO CART» на карточке «Brocolli - 1 Kg» | Счётчик «Items» в шапке показывает «1»; счётчик «Price» показывает «120» (1 × ₹120) | |
| 2 | Нажать иконку корзины, чтобы открыть выпадающую корзину | В корзине отображается «Brocolli - 1 Kg», количество «1 No.» и сумма «₹ 120» | |
