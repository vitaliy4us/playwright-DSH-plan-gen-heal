# TC-2.2 Изменение количества перед добавлением (should-adjust-quantity-before-adding)

**Предусловия:** открыта главная страница GreenKart (`https://rahulshettyacademy.com/seleniumPractise/#/`), корзина пуста

| № шага | Описание шага | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | На карточке «Brocolli - 1 Kg» нажать «+» дважды | Поле количества показывает «3» | |
| 2 | Нажать «–» один раз | Поле количества показывает «2» | |
| 3 | Нажать «–» ещё два раза | Количество никогда не опускается ниже «1»; поле количества показывает «1» | |
| 4 | Нажать «ADD TO CART» | Счётчик «Items» показывает «1», счётчик «Price» показывает «120» (1 × ₹120) | |
| 5 | Открыть выпадающую корзину | Корзина показывает «Brocolli - 1 Kg», «1 No.» и «₹ 120» | |
