# TC-4.2 Успешное размещение заказа (should-place-order-successfully)

**Предусловия:** открыта главная страница GreenKart, корзина пуста

| № шага | Описание шага | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | Добавить 2 шт. «Tomato - 1 Kg» (₹16 за шт.) в корзину и нажать «PROCEED TO CHECKOUT» | Страница корзины показывает «No. of Items : 1» и сумму 32 | |
| 2 | Нажать «Place Order» | URL становится `#/country` | |
| 3 | Выбрать «India» в списке стран, отметить чекбокс Terms & Conditions и нажать «Proceed» | Появляется сообщение «Thank you, your order has been placed successfully»; после авторедиректа URL возвращается на главную `#/`; счётчик «Items» показывает «0» (корзина очищена) | |
