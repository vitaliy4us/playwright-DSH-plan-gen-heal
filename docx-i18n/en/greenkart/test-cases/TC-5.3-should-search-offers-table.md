# TC-5.3 Searching the offers table (should-search-offers-table)

**Preconditions:** the Top Deals page is open (`https://rahulshettyacademy.com/seleniumPractise/#/offers`) in a new tab

| Step # | Step description | Expected result | Actual result |
|---|---|---|---|
| 1 | Open the offers page | The table shows all rows with the columns "Veg/fruit name", "Price", "Discount price" | |
| 2 | Type "Orange" into the "Search:" box | Only the "Orange" row is shown, with its price and its discount price | |
| 3 | Clear the search box | The full table is restored | |
