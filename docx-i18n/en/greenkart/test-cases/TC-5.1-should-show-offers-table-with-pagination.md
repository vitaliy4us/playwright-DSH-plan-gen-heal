# TC-5.1 Showing the offers table with pagination (should-show-offers-table-with-pagination)

**Preconditions:** the GreenKart main page is open (`https://rahulshettyacademy.com/seleniumPractise/#/`)

| Step # | Step description | Expected result | Actual result |
|---|---|---|---|
| 1 | Click "Top Deals" in the header | A new tab opens with the URL `#/offers`; the table has the columns "Veg/fruit name", "Price" and "Discount price" | |
| 2 | With a page size of 5, click "Next" | The displayed rows change to the next page (for example Pineapple, Orange, Mango, Guava, Dragon fruit) | |
| 3 | Click "Last" | The last page is shown; the "Last" button becomes inactive | |
