# TC-3.2 Застосування валідного промокоду (should-apply-valid-promo-code)

**Передумови:** відкрито головну сторінку GreenKart, у кошик додано 3 шт. «Brocolli - 1 Kg» (₹120 за шт.)

| № кроку | Опис кроку | Очікуваний результат | Фактичний результат |
|---|---|---|---|
| 1 | Відкрити кошик і натиснути «PROCEED TO CHECKOUT» | URL стає `#/cart`; «Total Amount :» дорівнює 360 | |
| 2 | Ввести «rahulshettyacademy» в поле «Enter promo code» і натиснути «Apply» | З'являється повідомлення «Code applied ..!» | |
| 3 | Перевірити розрахунок знижки | «Discount : 10%» | |
| 4 | Перевірити підсумкову суму | «Total After Discount : 324» (360 − 10%) | |
