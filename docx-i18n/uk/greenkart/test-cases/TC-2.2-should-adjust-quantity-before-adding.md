# TC-2.2 Зміна кількості перед додаванням (should-adjust-quantity-before-adding)

**Передумови:** відкрито головну сторінку GreenKart (`https://rahulshettyacademy.com/seleniumPractise/#/`), кошик порожній

| № кроку | Опис кроку | Очікуваний результат | Фактичний результат |
|---|---|---|---|
| 1 | На картці «Brocolli - 1 Kg» натиснути «+» двічі | Поле кількості показує «3» | |
| 2 | Натиснути «–» один раз | Поле кількості показує «2» | |
| 3 | Натиснути «–» ще два рази | Кількість ніколи не опускається нижче «1»; поле кількості показує «1» | |
| 4 | Натиснути «ADD TO CART» | Лічильник «Items» показує «1», лічильник «Price» показує «120» (1 × ₹120) | |
| 5 | Відкрити випадний кошик | Кошик показує «Brocolli - 1 Kg», «1 No.» і «₹ 120» | |
