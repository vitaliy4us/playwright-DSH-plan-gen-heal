# TC-3.1 Відхилення невалідного промокоду (should-reject-invalid-promo-code)

**Передумови:** відкрито головну сторінку GreenKart, у кошик додано 3 шт. «Brocolli - 1 Kg» (₹120 за шт.)

| № кроку | Опис кроку | Очікуваний результат | Фактичний результат |
|---|---|---|---|
| 1 | Відкрити кошик і натиснути «PROCEED TO CHECKOUT» | URL стає `#/cart`; сума 360 | |
| 2 | Ввести «INVALID123» в поле «Enter promo code» і натиснути «Apply» | З'являється повідомлення «Invalid code ..!» | |
| 3 | Перевірити розрахунок без знижки | «Discount : 0%» і «Total After Discount : 360» залишаються без змін | |
