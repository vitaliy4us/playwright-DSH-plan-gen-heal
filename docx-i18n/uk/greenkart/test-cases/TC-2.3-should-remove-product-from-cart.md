# TC-2.3 Видалення товару з кошика (should-remove-product-from-cart)

**Передумови:** відкрито головну сторінку GreenKart (`https://rahulshettyacademy.com/seleniumPractise/#/`), кошик порожній

| № кроку | Опис кроку | Очікуваний результат | Фактичний результат |
|---|---|---|---|
| 1 | Додати «Brocolli - 1 Kg» до кошика | Лічильник «Items» показує «1» | |
| 2 | Додати «Cauliflower - 1 Kg» до кошика | Лічильник «Items» показує «2» | |
| 3 | Відкрити кошик і натиснути «×» поруч із «Brocolli - 1 Kg» | «Brocolli - 1 Kg» більше не відображається в кошику; лічильник «Items» показує «1»; лічильник «Price» показує «60» (залишилася лише Cauliflower) | |
