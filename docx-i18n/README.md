# Локализованные версии документации

Здесь собираются английская и украинская версии сводного документа
`Playwright-Test-Agents-Documentation.docx`.

## Что где лежит

```
docx-i18n/
  en/                      переведённые (или уже английские) документы
    course/                README курса + 6 уроков
    greenkart/             README, specs/, test-cases/, skills/, agents/, BUG-*, SESSION-NOTES
    conduit/               README, conduit.plan.md, prompts.txt, SESSION-NOTES
  uk/                      то же самое на украинском
  build-i18n.py            сборщик локализованных .docx
```

## Как собрать

```bash
python docx-i18n/build-i18n.py en uk     # или только en / только uk
```

Сборщик переиспользует конвертер markdown из `C:\Users\vital\AI\build-docx.py`, поэтому
оформление (заголовки Word, таблицы с рамками, блоки кода, списки, frontmatter) полностью
совпадает с русской версией. Результат кладётся в корень проекта как
`Playwright-Test-Agents-Documentation-EN.docx` и `-UK.docx`, после чего переносится в `C:\Users\vital\AI`.

Сборщик **не падает**, если чего-то не хватает: он собирает то, что есть, и печатает список
отсутствующих файлов — удобно проверять прогресс перевода.

## Что переводится, а что нет

Правила, по которым делались переводы (переданы агентам-переводчикам):

- **сохраняется структура markdown**: уровни заголовков, маркеры списков, таблицы, блоки кода,
  цитаты, чек-боксы `[ ]` / `[x]`, YAML-frontmatter;
- **не переводятся**: код, команды, пути и имена файлов, URL, CSS-селекторы и классы
  (`.cart-count`, `.totAmt`), идентификаторы, имена тестов вида `should-...`, названия инструментов
  Playwright (`test_run`, `planner_save_plan`), названия продуктов (Playwright, GreenKart, Conduit,
  DeepSeek Harness, MCP, CLI) и ключи хранилища (`app_data_info`);
- **внутри блоков кода код не меняется, а документация переводится**: комментарии `#` и `//`
  (bash, YAML, JSONC, JS), подписи в ASCII-схемах и текстовые шаблоны-примеры (например, шаблоны
  `SKILL.md` в уроке 2). Это уточнение появилось после проверки: первая версия правила запрещала
  трогать блоки целиком, из-за чего в переводах остались русские комментарии, схема петли и шаблоны;
- **строки интерфейса приложения остаются английскими** («ADD TO CART», «You cart is empty!») —
  это то, что пользователь видит на экране, и в тестах они значатся дословно;
- **термины приводятся к единому глоссарию**: план тестирования → test plan / план тестування,
  дефект → defect / дефект, корзина → cart / кошик и так далее.

## Проверка качества

```bash
python docx-i18n/check-translations.py
```

Скрипт ищет в английском дереве кириллицу (норма — 0), а в украинском — буквы `ы`, `ъ`, `э`, `ё`,
которых в украинском алфавите нет: их наличие означает непереведённый русский фрагмент. Именно так
были найдены русские комментарии внутри блоков кода на первом прогоне.
